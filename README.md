# Paragon Lite Terms of Service

This repository contains the static HTML Terms of Service for Paragon Lite.

## Publish with GitHub Pages
1. Open **Settings** for this repository.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish deploying. The expected URL is:
   https://zulkifill.github.io/Paragon-Lite-Terms-of-Service/

The entry page is `index.html`. No build tools or paid hosting are required for a public repository.

## Before release
Review the terms against the app's real functionality and the laws that apply to its operator and users. This is a general template, not legal advice.
